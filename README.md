# Alerta de Licitações — Olhary

Página estática em HTML e CSS, com o degradê roxo e azul da Olhary.

## Arquivos
- index.html: página completa e estilos.
- alerta-olhary.png: imagem usada na página.

## Publicar
1. Extraia este ZIP.
2. Envie os arquivos extraídos para a raiz de um repositório GitHub.
3. Importe esse repositório na Vercel como projeto estático (Other).
4. Não é necessário instalar dependências nem executar build.

Abra index.html no navegador para visualizar localmente.

## Editar
- Textos e cores estão em index.html.
- O convite do WhatsApp aparece em dois botões. Atualize ambos ao trocar de grupo.
- A data 09/11 aparece no texto e na imagem.
- A imagem original usa verde; o CSS aplica hue-rotate(185deg) para exibi-la em roxo.

Este pacote não inclui credenciais, configurações internas do Sites ou arquivos Git.
